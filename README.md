# 🌙 رحلة المسلم الصغير

منصة عربية تفاعلية للتعلم باللعب، مصممة للهاتف والآيباد والحاسوب.

## الأنشطة
- مدينة الحروف: الحروف العربية وأمثلة مصورة.
- حديقة القراءة: قراءة كلمات واختيار معناها.
- مرسم الكتابة: تدريب باللمس أو الفأرة.
- جزيرة الحساب: تمارين جمع وطرح متجددة.
- بستان القيم والأذكار: أذكار وآداب وسلوكيات حسنة.
- تحدي الذكاء: ذاكرة وتركيز.
- نجوم وتقدم محفوظان محلياً على الجهاز.
- مؤثرات صوتية أصلية مولدة داخل المتصفح، ونطق صوتي عند دعم الجهاز.
- PWA: تثبيت وتشغيل دون اتصال بعد أول زيارة ناجحة.

## النشر
فعّل GitHub Pages من Settings → Pages → Build and deployment → Source: GitHub Actions. سيُنشر الموقع تلقائياً عند كل تحديث لفرع main.

الرابط المتوقع: https://teag3.github.io/Child-game/

## الخصوصية
لا توجد حسابات أو تحليلات أو إرسال لبيانات الطفل. التقدم محفوظ محلياً في المتصفح.
